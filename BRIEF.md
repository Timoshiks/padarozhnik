# BRIEF.md

## 1. Продукт

Интерактивный веб-прототип сервиса автотуризма «Падарожнiк» (раздел «Туризм» в экосистеме «Белоруснефть») в формате SPA, объединяющий карту достопримечательностей, конструктор маршрутов с ИИ-ассистентом и систему вознаграждений за чекины.

## 2. Пользователь и контекст

Живая демонстрация сценария. Приложение открывается сразу в разделе карты и сразу показывает карту с заправками (переход из главного меню показывать не нужно). Весь интерфейс работает исключительно на локальных тестовых данных (моках) без подключения внешних API и бэкенда.

## 3. Ключевой сценарий (Happy Path)

1. **Вход:** Пользователь нажимает тумблер на экране с картой -> На карте появляются помимо АЗС туристические зоны, список достопримечательностей, плашка ии агента

2. **Планирование с ИИ в реальном времени:**Пользователь нажимает на всплывающую плашку с ии-ассистентом, говорит ему детали его поездки, высвечивается чат с агентом как всплывающее окно снизу и на карте в реальном времени выстраивается маршрут(эффект разработки как с ии агентом), агент задает направляющие вопросы тем же всплывающим сообщений.

3. **Умная подсказка АЗС:** При составлении маршрута ии-ассистент задает вопросы по поводу добавления сетей АЗС для перерыва, пользователь может как писать текст, так и говорить. Когда маршрут делается сам в конструкторе, при добавлении определенных мест делаются “рекомендации приложением“

4. **Финал:** Когда маршрут составлен со всеми рекомендациями, пользователь нажимает кнопку перенести маршрут в навигатор.

## 4. Состав MVP

* **Главный экран:** интерактивная карта с динамической отрисовкой маршрута, отображающая кластерами все АЗС, достопримечательности( при приближении кластер распадается на более мелкие кластеры), снизу меню 

* **Плашка ИИ-ассистента:** компактный виджет общения, при нажатии переносится в всплывающее уведомление снизу, при общении перестраивает маршрут на карте в реальном времени

* Профиль пользователя с его ачивками и полученными бонусами.

* **Всплывающие окна (3 состояния):**

  1. Окно описания достопримечательности с кнопкой «Отметиться».

  2. Финальное окно с предложением экспортировать маршрут в навигатор.

  3. Всплывающее окно с вопросами насчет добавления АЗС, пит-стопов в маршрут пользователя

## 5. Чего делать НЕЛЬЗЯ (Out of Scope)

* Никакого подключения бэкенда, баз данных, платных LLM и картографических API — только визуал на тестовых данных.

* Никакого роутинга между отдельными страницами — весь флоу работает на одном экране через всплывающие окна и смену состояний.

* Никакой реальной проверки GPS-координат, оплаты и внешних интеграций.
