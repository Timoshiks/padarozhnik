# DESIGN.md — Дизайн-контракт сервиса «Падарожнiк» (Белоруснефть Туризм)

## 0. Контекст и архитектура интерфейса

Продукт представляет собой интерактивный SPA-прототип сервиса автотуризма «Падарожнiк» в экосистеме «Белоруснефть», объединяющий карту достопримечательностей и АЗС, ИИ-ассистента для построения маршрутов в реальном времени и систему вознаграждений за чекины.
Весь пользовательский путь (Happy Path) строится внутри одного экрана карты без страничного роутинга: переключение режимов, списки локаций, карточки мест, диалог с ИИ-агентом и экспорт маршрута работают исключительно через смену состояний карты и всплывающие шторки (Bottom Sheets).

## 2. Типографика и шрифты

### 2.1. Запрещенные шрифты

Прямой запрет на использование в проекте семейств: **`Inter`, `Roboto`, `Arial`, `Open Sans`, `Helvetica**`, а также системных фоллбэков `system-ui` в качестве основного шрифта.

### 2.2. Шрифтовые семейства и токены

В проекте используются ровно **две** шрифтовые семьи, зафиксированные через CSS-переменные:

* `--font-display: 'Unbounded', sans-serif` — акцидентный геометрический гротеск для заголовков шторок, названий достопримечательностей (замена заголовка «АЗК 10» в **реф 3**), крупных цифр бонусов в профиле и бейджей кластеров на карте (**реф 1**).


* `--font-text: 'Onest', sans-serif` — нейтральный гуманистический гротеск с открытой апертурой для списков локаций (**реф 1, 2**), адресов, сообщений чата с ИИ-ассистентом и подписей в кнопках действий (**реф 3, 4**).



### 2.3. Правила применения и кириллица

1. **Проверка кириллицы:** оба шрифта (`Unbounded` и `Onest`) перед подключением проходят обязательную проверку на поддержку полного кириллического набора, включая графемы белорусского языка (`і`, `ў` для логотипа и заголовка «Падарожнiк») и символ белорусского рубля/баллов.


2. **Табличные цифры (`tabular-nums`):** ко всем числовым данным (счетчики внутри кластеров `20+`, `50+`, `100+` из **реф 1**, тайминг маршрута, начисленные бонусы и прогресс ачивок) принудительно применяется правило:


```css
.numeric, [data-numeric="true"] {
  font-variant-numeric: tabular-nums;
  font-feature-settings: "tnum" 1;
}

```


Значения не должны смещать соседние элементы при динамическом перестроении маршрута ИИ-агентом в реальном времени.



### 2.4. Шкала типографики

* `Title-Lg` (Заголовок карточки объекта — реф 3): `var(--font-display)`, `22px / 28px`, `font-weight: 700`, `letter-spacing: -0.02em`.


* `Title-Md` (Заголовки секций внутри карточки и чата — реф 3): `var(--font-display)`, `18px / 24px`, `font-weight: 600`, `letter-spacing: -0.01em`.


* `List-Title` (Название точки в списке шторки — реф 1, 2): `var(--font-text)`, `17px / 22px`, `font-weight: 600`.


* `Body-Md` (Реплики ИИ-ассистента, описание места, поле ввода — реф 1, 3, 4): `var(--font-text)`, `15px / 21px`, `font-weight: 400`.


* `Caption` (Адреса в списке, подписи под иконками действий — реф 1, 2, 3): `var(--font-text)`, `13px / 17px`, `font-weight: 500`.


* `Cluster-Badge` (Цифры кластеров на карте — реф 1): `var(--font-display)`, `14px / 14px`, `font-weight: 700`, `tabular-nums`.

## 3. Цвет и правило одного акцента

### 3.1. Монохромная база и акцент

Интерфейс строится как чистый монохромный канвас (теплый алебастровый фон шторок, светло-серые контейнеры групп и графитовый текст, как в нижнем меню и списках **реф 1, 2, 3**) с **единственным** изумрудно-зеленым акцентом экосистемы «Белоруснефть» (**реф 1, 3**).

### 3.2. Жесткое ограничение акцентного цвета (`--color-accent`)

Акцентный цвет разрешен строго в **трех местах**:

1. **Ключевое целевое действие (Primary CTA):** активный тумблер режима «Туризм» на карте, главная круглая иконка целевого действия в карточке места («Отметиться» / «Построить маршрут» в **реф 3**), кнопка «Перенести в навигатор» и кнопка отправки/голосового вызова ИИ-агента (**реф 4**).


2. **Критичная метрика / число:** маркеры кластеров и активная нитка маршрута на карте (**реф 1**), а также счетчик начисленных бонусов за чекин в профиле.


3. **Состояние ошибки (`--color-danger`):** системный индикатор недоступности точки или ошибки ввода (используется только при возникновении ошибки).

*Примечание по адаптации референсов:* Разноцветные круги (желтый и оранжевый) из блока возможностей **реф 3** и сине-голубые кластеры из **реф 1** запрещены. Второстепенные действия в **реф 3** и обычные кластеры АЗС окрашиваются в спокойный графитовый монохром (`--bg-surface-active` / `--text-primary`), а изумрудный акцент (`--color-accent`) отдается только туристическим кластерам и главной кнопке действия.

### 3.3. Цветовые токены (CSS Variables)

```css
:root {
  /* Поверхности (Surfaces) */
  --bg-canvas: #F4F5F2;          /* Подложка карты до загрузки тайлов */
  --bg-sheet: #FFFFFF;           /* Основной фон шторок и нижнего меню (реф 1, 2, 3) */
  --bg-container: #F2F3F0;       /* Серый контейнер возможностей внутри карточки (реф 3) */
  --bg-card-inner: #EAECE7;      /* Плитки быстрых действий внутри серого контейнера (реф 3) */
  --bg-glass: rgba(255, 255, 255, 0.86); /* Только для элементов поверх карты (реф 1, 4) */

  /* Текст и иконки (Typography & Icons) */
  --text-primary: #141715;       /* Заголовки, основные названия, активная иконка меню (реф 1, 3) */
  --text-secondary: #6E736F;     /* Адреса, плейсхолдеры поиска и ИИ-чата (реф 1, 2, 4) */
  --text-on-accent: #FFFFFF;     /* Текст внутри акцентных кнопок и кластеров (реф 1, 3) */

  /* Единственный акцент и статус ошибки */
  --color-accent: #009A49;       /* Изумрудный акцент (CTA, критичная метрика/кластер — реф 1, 3) */
  --color-accent-soft: #E6F5ED;  /* Мягкая подложка для выбранного пит-стопа в чате ИИ */
  --color-danger: #D92D20;       /* Только для критических ошибок */

  /* Границы и разделители */
  --border-subtle: #E4E6E1;      /* Тонкая обводка плашки ИИ-ввода (реф 4) и ручки шторки (реф 1-3) */
}

```

## 4. Сетка, радиусы и архитектура экрана (SPA Layout)

### 4.1. Параметры контейнера и сетки

* **Мобильный вьюпорт (Mobile-First SPA):** `max-width: 430px`, `height: 100dvh`, `overflow: hidden` (поверхность карты фиксирована на весь экран, скролл работает только внутри открытых шторок, как в **реф 2** и **реф 3**).


* **Базовый модуль сетки:** `4px`. Горизонтальные отступы экрана и шторок: `padding-inline: 16px` (**реф 1, 2, 3, 4**).


* Сетка блока возможностей (реф 3): CSS Grid из 3 равных колонок (`grid-template-columns: repeat(3, 1fr)`), `gap: 8px` внутри контейнера с `padding: 16px`.



### 4.2. Кастомная система радиусов (взамен дефолтного shadcn)

* `--radius-sheet: 28px 28px 0 0` — верхние скругления выдвижных шторок и главной фотографии объекта (**реф 1, 2, 3**).


* `--radius-container: 24px` — серый контейнер возможностей в карточке места (**реф 3**) и всплывающие карточки сообщений ИИ-ассистента (**реф 4**).


* `--radius-tile: 18px` — вложенные вертикальные плитки действий внутри контейнера (**реф 3**) и плашка активного пункта нижнего меню (**реф 1, 2**).


* `--radius-pill: 9999px` — поисковая строка, кнопки зума/геолокации и кластеры на карте (**реф 1**), круги иконок действий (**реф 3**), а также поле ввода текста и кнопка голосового ввода ИИ (**реф 4**).



### 4.3. Высотные состояния шторок (Snap Points)

1. Collapsed (Свернутый список — реф 1): высота `220px` над нижним меню (показывает ровно 2 локации из списка, оставляя 65% экрана под карту и кластеры).


2. Half-Expanded (Развернутый список мест — реф 2): максимальная высота развертывания виджета со списком мест строго ограничена `58dvh` (верхняя граница проходит под основными кластерами карты, внутри списка включается вертикальный скролл).


3. Card-Expanded (Детальная карточка места / Финал маршрута — реф 3): максимальная высота виджета карточки составляет `82dvh` (над карточкой остается видимой полоска карты с затемнением и строкой поиска).

## 5. Анатомия компонентов (Связь с мудбордом и BRIEF.md)

### 5.1. Главный экран карты и верхний бар (реф 1

 + BRIEF.md)

* **Верхний оверлей (`z-index: 20`):** отступ сверху `16px`. Состоит из пилюли поиска (`height: 52px`, `--radius-pill`, фон `--bg-glass` с `backdrop-filter: blur(12px)`) и круглой кнопки-тумблера туристического режима справа (`52×52px`, `--radius-pill`). При включении тумблера «Туризм» кнопка окрашивается в `--color-accent`, а на карте появляются туристические кластеры, список достопримечательностей и виджет ИИ-агента.


* Кластеры на карте (реф 1): круглые маркеры диаметра `48px` (`10+`, `20+`) и `56px` (`50+`, `100+`) с белой обводкой `2px` и тенью `0 4px 12px rgba(0,0,0,0.15)`. Кластеры базовых АЗС — темно-графитовые (`#262B28`), кластеры достопримечательностей и активного маршрута — акцентные (`--color-accent`). При клике или зуме кластер распадается на более мелкие точки.


* Плавающие контролы карты (реф 1): вертикальный стек справа (`right: 16px`, по центру видимой области карты): кнопки `+`, `-` и «Геолокация» (`48×48px`, `--radius-pill`, `gap: 10px`, фон `--bg-glass`).



### 5.2. Нижнее навигационное меню (реф 1, 2

)

* Фиксированный бар внизу экрана (`height: 64px` + `env(safe-area-inset-bottom)`, фон `--bg-sheet`, `z-index: 40`).


* 5 иконок навигации в один ряд. Активный раздел (Карта или Профиль с ачивками и бонусами) выделяется светло-серой подложкой `48×40px` со скруглением `--radius-tile` и залитой черной иконкой (`--text-primary`), неактивные иконки — контурные `2px` цвета `--text-secondary` (**реф 1**).



### 5.3. Шторка списка локаций (реф 1, 2

)

* Вверху по центру — индикатор перетаскивания (Drag Handle: `44×5px`, `--radius-pill`, цвет `--border-subtle`, отступ сверху `10px`).


* **Строка локации (АЗС или Достопримечательность):** высота `72px`, `padding: 12px 16px`, двухколоночная структура (`display: flex; justify-content: space-between; align-items: flex-start`).


* Слева: Название точки (`List-Title`, `--text-primary`) и под ним через `4px` адрес или категория объекта (`Caption`, `--text-secondary`). Названия и адреса заправок из **реф 1** и **реф 2** не используются — подставляются моковые туристические локации и пит-стопы «Белоруснефть».


* Справа: Бонусная награда за посещение (`+50 Б`) или статус точки в маршруте (`tabular-nums`).





### 5.4. Детальная карточка объекта и пит-стопа (реф 3

 + BRIEF.md)

Используется для трех состояний всплывающих окон из `BRIEF.md`: карточка достопримечательности, предложение пит-стопа АЗС и финальное окно экспорта маршрута.

* Шапка с фото (реф 3): полноширинное изображение `height: 220px`, верхние углы скруглены по `--radius-sheet`, поверх фото по центру сверху лежит полупрозрачный Drag Handle.


* Заголовочный блок (реф 3): отступ `16px`. Название локации (`Title-Lg`) и под ним адрес/регион (`Caption`, `--text-secondary`). *Строгое исключение:* правый счетчик расстояния (`4.2 км`) и блок «Виды топлива» из **реф 3** не переносятся.


* Плашка с возможностями (Бенто-контейнер действий — реф 3):


* Внешний контейнер: фон `--bg-container`, `--radius-container` (`24px`), `padding: 16px`, `margin-top: 16px`.


* Внутри — заголовок блока (`15px`, `font-weight: 600`) и сетка из 3 вертикальных карточек-плиток (`height: 124px`, `--bg-card-inner`, `--radius-tile`).


* В каждой плитке по центру размещается круг `52×52px` с иконкой `24×24px` и подпись в 2 строки снизу (`Caption`, `text-align: center`):


1. **Плитка 1 (Главная CTA):** «Отметиться» (чекин для получения бонусов) или «В навигатор» (в финальном окне) — круг залит акцентным цветом `--color-accent`, иконка белая.


2. **Плитка 2 (Вторичная):** «В маршрут» / «Добавить АЗС» — круг монохромный (`--bg-sheet`), иконка `--text-primary`.


3. **Плитка 3 (Вторичная):** «Аудиогид» / «О месте» — круг монохромный (`--bg-sheet`), иконка `--text-primary`.




* Нижний информационный блок (замена «Сервисов» из реф 3): краткое описание достопримечательности (до 3 строк) и список доступных удобств на пит-стопе в виде отдельных чипов (`gap: 8px`), **без** разделительных точек-буллитов.



### 5.5. Виджет и всплывающий чат ИИ-ассистента (реф 4

 + BRIEF.md)

Отвечает за живое планирование маршрута, голосовое/текстовое общение и умные подсказки по добавлению АЗС.

* Нижний узел ввода (реф 4): располагается над нижним меню (`bottom: 76px`, `padding-inline: 16px`, `z-index: 35`). Состоит из двух сгруппированных по горизонтали элементов (`display: flex; gap: 10px; align-items: center`):


1. Окно ввода текста (реф 4): вытянутая капсула (`flex: 1`, `height: 54px`, `--radius-pill`, фон `--bg-sheet`, граница `1px solid var(--border-subtle)`, тень `0 8px 24px rgba(0,0,0,0.08)`). Внутри слева — текстовый инпут, справа — иконка микрофона для диктовки (`24×24px`, `--text-primary`).
