# AGENTS.md — Инструкции для ИИ-агентов (Проект «Падарожнiк»)

## 1. Команды проекта (Bash)

* `pnpm dev` — запуск локального Vite dev-сервера.
* `pnpm build` — проверка типов (`tsc -b`) и production-сборка; **запускай после каждого изменения логики**, чтобы отловить ошибки строгого TypeScript до коммита.
* `pnpm lint` — проверка кода через ESLint и стилей токенов.
* `pnpm test` — запуск unit-тестов состояний маршрута и чекинов (`vitest run`).

---

## 2. Стек и архитектура (Что и Почему)

* **Стек:** React 19 + TypeScript (Strict) + Vite + Tailwind CSS (с полной перезаписью темы через CSS-переменные из `DESIGN.md`) + `vaul` / кастомный стейт-менеджер шторок.


* **Строгий Single-Screen SPA без роутера:** пакеты `react-router-dom` или `@tanstack/router` **запрещены**, потому что по `BRIEF.md` весь флоу (карта, переключение режима «Туризм», чат с ИИ, карточка места, профиль с ачивками и экспорт в навигатор) обязан работать на одном экране через смену состояний и всплывающие шторки (Bottom Sheets).


* **Только локальные моки (Zero Backend / Zero External API):** запрещено подключать платные LLM, внешние картографические движки с API-ключами (Google Maps, Mapbox), базы данных и реальную геолокацию `navigator.geolocation`, так как прототип создается для живой офлайн-демонстрации сценария без сетевых задержек и падений внешних сервисов.


* **Имитация живого ИИ-агента и карты:** карта с распадающимися при зуме кластерами и построение маршрута в реальном времени реализуются на детерминированных локальных моках и пошаговых таймерах (стриминг точек маршрута на карту при ответах пользователя в чате), чтобы создать визуальный эффект живой совместной разработки маршрута с ИИ.


* **Жесткий мобильный вьюпорт:** корневой контейнер фиксируется размерами `max-width: 430px`, `height: 100dvh`, `overflow: hidden`, потому что карта должна оставаться неподвижной подложкой, а скролл допустим только внутри открытых шторок.

## 3. Неочевидные ограничения (Бизнес и Дизайн-контракт)

* **TypeScript `strict: true` + `noUnusedLocals` / `noUnusedParameters`:** неиспользуемые переменные и неявный `any` ломают сборку `pnpm build`. Удаляй неиспользуемые пропсы сразу, чтобы не блокировать проверку сборок.
* **Три фиксированных Snap Points для шторок:**
1. `Collapsed` (`220px` над меню) — свернутый список на 2 локации, чтобы 65% экрана оставалось под карту и кластеры.


2. `Half-Expanded` (`58dvh` максимум) — развернутый список мест, чтобы верхняя граница шторки не перекрывала основные кластеры на карте.


3. `Card-Expanded` (`82dvh` максимум) — детальная карточка места, пит-стопа или финала маршрута, чтобы сверху оставалась видимой полоска карты и поиск.




* **Правило одного акцента (`--color-accent: #009A49`):** изумрудный цвет разрешен **только в 3 местах** — главное целевое действие (активный тумблер «Туризм», главная круглая кнопка «Отметиться» / «В навигатор», активная кнопка ИИ-голоса), критичная метрика/туристический кластер/нитка маршрута и статус ошибки (`--color-danger: #D92D20`). Запрещено красить второстепенные иконки в желтый или оранжевый, так как это дробит внимание на мобильном экране.


* **Запрет «пустого» `backdrop-filter: blur`:** размытие (`--bg-glass`) разрешено **только** поверх физически движущейся карты (поисковая строка, кнопки зума, плашка ввода и баннер вопроса ИИ-агента). На вложенных карточках внутри шторок `blur` запрещен, потому что над однотонным фоном он дает грязные артефакты и просаживает FPS.


* **Анти-слоп в типографике и мета-данных:**
* Запрещены шрифты `Inter`, `Roboto`, `Arial`, `Open Sans`, `Helvetica` и `system-ui` — используй строго токены `--font-display` (`Unbounded`) и `--font-text` (`Onest`) с поддержкой белорусской кириллицы (`і`, `ў` для «Падарожнiк»).


* Запрещены КАПС с разрядкой (`letter-spacing > 0.05em`) и буллиты-разделители (`•` или `·`) в списках удобств — они выдают шаблонную ИИ-генерацию; разделяй теги только через `gap: 8px` и монохромные чипы.


* Обязателен `font-variant-numeric: tabular-nums` на всех цифрах (кластеры `20+`, `50+`, `100+`, бонусы `+50 Б`, тайминг), иначе интерфейс будет дергаться при перестроении маршрута в реальном времени.




* **Запрет дефолтного `shadcn/ui` и лишнего контента из референсов:** стандартные радиусы `0.5rem` и бордеры `slate/zinc` запрещены — используй только кастомные токены `--radius-sheet` (`28px 28px 0 0`), `--radius-container` (`24px`), `--radius-tile` (`18px`) и `--radius-pill` (`9999px`). Не переноси цены на топливо и километраж в карточку объекта — там должны быть описание, награда за чекин и бенто-блок из 3 плиток действий.

## 4. Стандарты кода и структура директорий

```text
src/
├── components/
│   ├── map/          # Канвас карты, кластеры (48px/56px), линия маршрута, контролы зума
│   ├── sheets/       # Нижние шторки: список мест (58dvh), карточка/пит-стоп/финал (82dvh)
│   ├── ai-widget/    # Капсула ввода (54px), кнопка голоса (54x54px), всплывающий вопрос ИИ
│   ├── profile/      # Модальное состояние профиля с ачивками и полученными бонусами
│   └── ui/           # Кастомизированные примитивы (без дефолтных стилей shadcn)
├── mocks/            # Детерминированные моки туристических мест, АЗС и сценариев диалога ИИ
├── store/            # Глобальный стейт экрана (режим Туризм, активная шторка, маршрут, баллы)
└── styles/           # Переменные токенов из DESIGN.md и подключение Unbounded / Onest

```

* **Импорты и токены:** используй алиас `@/` для всех внутренних импортов. Цвета и скругления задавай только через CSS-переменные из `DESIGN.md` (`var(--bg-sheet)`, `var(--color-accent)` и т.д.), без хардкода HEX-значений в JSX.


* **Обработка ошибок и пустых состояний:** поскольку бэкенда нет, любые нештатные действия пользователя (например, пустой ввод в чат ИИ или повторный чекин) должны обрабатываться локальным fallback-сценарием с подсветкой `--color-danger` без выброса необработанных исключений в консоль.
